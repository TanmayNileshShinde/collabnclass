# Contributing to CollabNClass

Thank you for your interest in contributing to CollabNClass!

## Development Workflow

1. Fork or branch from `main`.
2. Follow code formatting and TypeScript typing standards.
3. Test WebRTC signalling and Canvas rendering locally before opening PRs.
4. Ensure all environment variables are documented in `.env.example`.

## Pull Request Guidelines

- Give PRs clear and descriptive titles following conventional commits (`feat:`, `fix:`, `docs:`, `chore:`).
- Document changes and test verification steps in the pull request description.
